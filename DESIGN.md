# Design Brief: Badhai Ho – Wedding & Event Films

## Tone & Differentiation
Luxury cinematic storytelling. Premium emotional branding. Netflix-inspired visual presentation. Minimal interface with maximum visual impact. Golden accents sparingly deployed for premium feel.

## Palette (OKLCH)
| Role | Light L | Chroma | Hue | Purpose |
| --- | --- | --- | --- | --- |
| Background | 0.08 | 0 | 0 | Matte black immersive canvas |
| Foreground | 0.95 | 0 | 0 | Pure white premium text |
| Accent (Gold) | 0.55 | 0.25 | 55 | CTAs, highlights, hover states |
| Muted | 0.20 | 0 | 0 | Secondary backgrounds, subtle depth |
| Muted Text | 0.60 | 0 | 0 | Supporting gray text |

## Typography
| Use | Font | Scale | Weight |
| --- | --- | --- | --- |
| Display (Hero, Section titles) | Playfair Display | 3.5rem–2rem | 400–700 |
| Body (Copy, descriptions) | Poppins | 1rem–0.875rem | 400–600 |
| Mono (Labels, metadata) | Geist Mono | 0.875rem | 400 |

## Structural Zones
| Zone | Background | Treatment | Elevation |
| --- | --- | --- | --- |
| Header/Nav | 0.08 0 0 | Minimal, border-b subtle | Card |
| Hero | Video overlay on 0.08 0 0 | Fullscreen cinematic backdrop | Elevated |
| Content Sections | Alternating 0.08/0.12 0 0 | Large imagery, 4:3 aspect ratio minimum | Base/Card |
| Film Cards | 0.12 0 0 | Gold border on hover, shadow-elevated | Elevated |
| Footer | 0.08 0 0 | border-t subtle, gold accent links | Base |

## Spacing & Rhythm
Mobile-first: 1rem sections. Tablet: 1.5rem gaps. Desktop: 2rem+ breathing room. Large imagery takes precedence. Whitespace is luxury.

## Component Patterns
- CTA buttons: gold background, black text, rounded-md, hover shadow-gold-glow
- Film cards: black bg, subtle border, large thumbnail, title overlay on hover
- Gallery grid: masonry layout, 2col mobile → 3col tablet → 4col desktop
- Testimonials: minimal card, centered text, author name in gold

## Motion Choreography
Fade-in on scroll (0.8s ease-in-out). Slide-up entrance for cards (0.6s). Smooth hover transitions (0.3s). No bounce, no flashiness. Cinematic pacing.

## Constraints
- Zero heavy gradients or neon effects
- Imagery dominates; minimal text overlay
- Gold sparingly (CTAs, active states, select highlights only)
- Mobile-responsive, no horizontal scroll
- Video backgrounds optimized for fast load

## Signature Detail
Gold accent glow (0 0 20px rgba(212,175,55,0.2)) on hover for premium tactile feedback. Playfair Display headlines at large scale for emotional impact.
